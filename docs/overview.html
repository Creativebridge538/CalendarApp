ロールと主要機能

Admin — 管理者

店舗全体の管理・意思決定を担う

  • キャスト管理（招待・報酬率設定）
  • エリア・ルーム管理
  • シフト確定 / 差し戻し
  • ルーム被りチェック
  • 修正申請の承認 / 却下
  • 空き枠登録・申請承認
  • 売上入力・月次集計
  • 報酬計算・明細確定
  • 店舗設定（締切ルール等）
  • 通知受信
Cast — キャスト

自分のシフト・報酬を管理する

  • シフト提出（日時・備考）
  • 提出済みシフトの確認
  • 締切後の修正申請
  • 空き枠の閲覧・申請
  • 報酬明細の確認
  • 通知受信
  • プロフィール設定

報酬計算式

支払総額 = 売上合計 × 報酬率 + ボーナス − 控除

ロケーションモード

店舗設定で4つのモードを選択可能。タイムライン等の表示もこれに連動する。

none 場所管理なし
area_only エリアのみ（ルームなし）
room ルームのみ
area_and_room エリア ＋ ルーム階層管理

タイムライン表示

シフトを横軸＝時間・縦軸＝日付のガントチャートで表示。ロケーションモードに応じてタブが切り替わる。

7日単位でページング可能。シフトのない日も含めて自由に前後移動できる。
